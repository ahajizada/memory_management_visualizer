# Memory Management Visualizer

## Overview
This project simulates memory allocation and deallocation processes for heap and stack memory. It helps visualize memory usage and teaches concepts like fragmentation and memory leaks.

## Features
- Allocate memory blocks in the heap or stack.
- Deallocate specific memory blocks by ID.
- Visualize the current memory state.

## How to Build
1. Clone the repository:
   - git clone https://github.com/ahajizada/memory_management_visualizer.git
   - cd memory_management_visualizer

2. Compile the program:
   make

## How to Run
1. Run the executable:
   ./memory_management_visualizer
2. Follow the on-screen instructions to allocate, deallocate, and visualize memory.
